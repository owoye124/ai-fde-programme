# AI Forward Deployed Engineer Programme

A 20-week programme taking me from AI/Data Science to job-ready
AI Forward Deployed Engineer.

## Structure

Phased, from foundations to a production capstone. Each phase has a
mini-project and a skills gate that must be passed before progressing.

## Capstone

Terminal Turnaround Intelligence Platform: an end-to-end AI system
for a fuel terminal operator, covering prediction, retrieval,
agents, deployment and monitoring.
